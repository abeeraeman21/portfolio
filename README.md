# Abeera Eman — Portfolio Website

A responsive one-page portfolio built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — page content and structure
- `style.css` — responsive dark navy and purple styling
- `script.js` — mobile menu, scroll reveal, active navigation, project-link copy, and contact form behavior

## Run locally
Open `index.html` in a modern browser. For development, you can also use the VS Code Live Server extension.

## Personalize before publishing
1. In `index.html`, add your real GitHub/LinkedIn/Upwork links if you want them shown.
2. In `script.js`, replace `YOUR_EMAIL_HERE` with the email address where you want to receive enquiries.
3. Only keep skills and services you can confidently offer. The portfolio currently presents your skills as a learning journey and avoids invented client experience.
4. Update the project description so it matches the exact features your Learn with Dua website currently has.
5. Add your own photo only if you want one; the hero currently uses a code illustration and does not use a placeholder portrait.

## Publish on GitHub Pages
You can upload these three files to a new GitHub repository and enable GitHub Pages in the repository's Settings → Pages. If you prefer to add this portfolio to an existing repository, back up the current files first so you do not overwrite your Learn with Dua website.
